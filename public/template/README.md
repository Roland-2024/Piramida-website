# Draft frontend assets

Selected images and fonts from the owner's `Piramida.zip` static template.
The animated homepage is based on `animation.html`; its timed radial stripe
reveal, word highlights and blue wipe are implemented in the public Vite bundle.

Font license files are included alongside the fonts. Original filenames/case
are preserved for compatibility on Linux. CMS-managed media remains in Laravel
Storage and is not duplicated here.

The 76 MB Iceland sample video, missing template scripts, unused images and
Tailwind CDN were intentionally not imported. Real video can be configured on
a CMS Page Section. This asset set is provisional until the final template.
